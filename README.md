# Cheatbusters Backend

A small Python backend organized into routes, services, schemas, and utility modules.

## Overview

A small Python backend organized into routes, services, schemas, and utility modules. The description and capabilities in this document are limited to behavior that can be verified in the repository source.

## Key Features

- Separated route, service, and schema modules

## Tech Stack

- Python

## Architecture

A lightweight route → service organization.

## Project Structure

- `app/routes/` — route definitions
- `app/services/` — application logic
- `app/schemas/` — data schemas
- `app/utils/` — helpers

## Getting Started

Run the commands appropriate to the project root:

```bash
pip install -r requirements.txt
```
